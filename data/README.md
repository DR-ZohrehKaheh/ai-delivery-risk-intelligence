# Data acquisition

Download the [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) directly from Kaggle.

The source lists its license as **CC BY-NC-SA 4.0**. Follow all applicable attribution and non-commercial conditions.

Create `data/raw/` and put these original files there:

- `olist_orders_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_order_items_dataset.csv`

The exploratory notebooks may need the other Olist CSVs. Raw data are deliberately not redistributed in this repository.
