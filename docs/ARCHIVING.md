## Rights and future archiving

The maintainer approved public availability for technical review and scholarly citation without a general software reuse licence. The archive uses the custom rights statement **All rights reserved — no general software reuse licence**; see [RIGHTS.md](../RIGHTS.md). No open-source software licence was assigned. The excluded Olist dataset retains its separate licence.

This release was deposited manually in the maintainer's existing Zenodo account so that the custom rights could be set before publication. Automatic GitHub archiving is disabled for this repository to prevent a default licence from being assigned. Keep it disabled unless an explicitly approved rights configuration has been verified.

For future releases, use **New version** on the existing Zenodo record rather than creating a separate deposit. Verify the files, author, version and rights before publishing; then update the version DOI in the citation files. The concept DOI remains the same.
