# Dashboard screenshots

This directory contains selected development screenshots of the local Streamlit prototype:

- `single_order_prediction.jpeg` — experimental single-order risk-score output.
- `batch_assessment.jpeg` — batch assessment on **30 synthetic sample orders**.
- `risk_distribution.jpeg` — distribution of model scores for the same synthetic orders.

These images document the working prototype at the time of capture. The Streamlit interface may differ slightly from the current `app.py`. The synthetic examples are **not** evidence of predictive accuracy or performance in production. See [project README](../README.md) for retrospective validation results and limitations.
